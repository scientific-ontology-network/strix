# Strix - A lean ontology explorer


## Development

This tool is being developed using [Tauri](https://v2.tauri.app/). It is separated into a frontend written in Rust and a backend written in Typescript using the [Angular](https://angular.dev/) framework. In order to run both systems, use ```npm run tauri dev```. **For the time being, this library is co-developed with [strix-roost](https://github.com/scientific-ontology-network/strix-roost) and, therefore, expects it to be stored at `../strix-roost`**.
